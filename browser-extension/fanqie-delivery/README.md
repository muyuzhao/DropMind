# DropMind 番茄投递扩展

扩展负责领取 DropMind 投递队列中的单章任务、填入章节，并在作者点击“自动发布本章”后完成当前章节的检测与定时发布流程。扩展不会自动连续领取和发布后续章节。

## 安装

1. 打开 Chrome 的 `chrome://extensions/`。
2. 开启右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择本目录 `browser-extension/fanqie-delivery`。
5. 在 DropMind 第6步“发布准备”中复制连接令牌。
6. 点击浏览器工具栏中的扩展图标，填写 `http://127.0.0.1:3000` 和连接令牌，执行“保存并测试”。

## 投递

1. 在 DropMind 正文章节页面保存标题和正文，再点击“投递到番茄”。
2. 打开番茄作家后台，使用右下角的 DropMind 面板领取下一章。
3. 点击“进入创建章节”，或手动进入对应作品的创建章节页面。
4. 点击“填入页面”，核对章数、标题和正文。
5. 点击“自动发布本章”：扩展会继续提交错别字提示、选择仅基础检测、选择不使用 AI，并按工作台日期在 12:00 定时发布。
6. 扩展识别到发布成功后会自动回写；若页面整页跳转导致结果无法识别，可点击“我已提交审核”手动回写。

如果番茄页面改版导致自动识别失败，可以使用面板里的“复制标题”和“复制正文”继续完成投递，正文不会丢失。
