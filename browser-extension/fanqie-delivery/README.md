# DropMind 番茄投递扩展

扩展负责领取 DropMind 投递队列中的单章任务、填入章节，并自动完成当前章节的检测与定时发布流程。扩展不会自动连续领取和发布后续章节。

## 安装

1. 打开 Chrome 的 `chrome://extensions/`。
2. 开启右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择本目录 `browser-extension/fanqie-delivery`。
5. 在 DropMind 第6步“发布准备”中复制连接令牌。
6. 点击浏览器工具栏中的扩展图标，填写 `http://127.0.0.1:3000` 和连接令牌，执行“保存并测试”。

## 投递

1. 在 DropMind 正文章节页面保存标题和正文，选择发布日期，再点击“投递到番茄”。
2. 点击“自动投递第N章”。工作台和服务端都会选择当前队列中章节号最小的任务，不能从后面的章节跳过前章。
3. 扩展会自动领取当前章、进入对应作品的创建章节页、填入章数/标题/正文并点击“下一步”。
4. 如出现错别字提示，扩展会直接提交；随后选择“仅基础检测”、选择不使用 AI、开启定时发布，并按工作台日期在 12:00 确认发布。
5. 扩展识别到发布成功后会自动回写 DropMind，全程无需点击番茄页面或扩展面板。

扩展更新到新版本后，需要在 `chrome://extensions/` 中点击一次“重新加载”，让版本 0.3.0 的脚本生效。

如果番茄页面改版导致自动识别失败，可以使用面板里的“复制标题”和“复制正文”继续完成投递，正文不会丢失。

工作台中的“打开后台手动投递”只打开番茄作者后台，不启动自动领取、填入或发布流程。
