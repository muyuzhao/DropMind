# 提示词方案库设计

## 目标

为小说工作台增加可复用的提示词方案库。每套方案包含完整的六步提示词；新建小说时选择一套方案，并将六个模板复制为该小说的独立快照。方案后续修改不影响已有小说。

## 核心规则

1. 系统首次运行时自动创建一套“系统默认版”方案，内容来自当前六套默认提示词。
2. 每套方案必须同时拥有选题、分卷大纲、核心设定、剧情单元、分章大纲和正文六个模板。
3. 新建小说必须选择一个方案，默认选中当前默认方案。
4. 创建小说时复制方案内容，小说之后继续使用自己的六个模板副本。
5. 修改、重命名或删除方案均不改变已有小说。
6. 系统默认方案不可删除；当前默认方案不可删除，必须先将其他方案设为默认。

## 数据模型

新增两张 SQLite 表：

- `prompt_schemes`：`id`、`name`、`description`、`is_system`、`is_default`、创建时间和修改时间。
- `prompt_scheme_templates`：`id`、`scheme_id`、六步键之一、模板正文、创建时间和修改时间。

`prompt_scheme_templates` 对 `(scheme_id, key)` 设置唯一约束。删除自建方案时级联删除其六个模板。

现有 `prompt_templates` 表继续保存每本小说的模板快照，不改为外键引用方案，以保证已有小说稳定。

## 方案管理页面

新增 `/novels/prompts` 页面，并在小说首页增加“提示词管理”入口。

页面左侧展示方案列表和状态标识：系统、默认、自建。右侧展示当前方案的名称、说明和六步标签页。用户一次编辑其中一个模板，保存后仍停留在当前步骤。

支持操作：

- 新建方案：以系统默认模板为初始内容；
- 复制方案：复制名称、说明和六个模板，并在名称后追加“副本”；
- 重命名与修改说明；
- 编辑六个模板；
- 设置为默认；
- 删除自建且非默认方案；
- 将单个模板恢复为系统内置内容。

保存模板前显示其中使用的命名占位符。每一步必须保留该模板所需的必要占位符；缺少时禁止保存并列出缺失项。

## 新建小说流程

`/novels/new` 页面增加“提示词方案”下拉框，显示方案名称和默认标记。页面初始选中默认方案。

提交时服务端验证方案存在且包含六个模板，然后在一个数据库事务中：

1. 创建小说；
2. 读取所选方案的六个模板；
3. 将六个模板写入该小说的 `prompt_templates` 快照。

若方案在提交前已被删除或内容不完整，创建失败且不留下半成品小说。

## 迁移与兼容

数据库初始化采用幂等建表和种子逻辑。已有本地数据库升级时创建新表并补入系统默认方案，不修改已有小说和已有 `prompt_templates` 数据。

现有创建接口未提供方案 ID 时，服务端使用当前默认方案，以兼容旧调用和备份恢复流程。

## 错误处理

- 方案名称为空或重名时拒绝保存；
- 六步模板不完整时拒绝创建小说；
- 必要占位符缺失时拒绝保存模板；
- 系统方案或默认方案删除请求返回明确错误；
- 设置默认方案使用事务，确保任意时刻只有一个默认方案；
- 删除或切换方案前，未保存编辑内容需二次确认。

## 验收标准

1. 首次启动和旧数据库升级后均存在一套系统默认方案。
2. 可以新建、复制、编辑、重命名和设置默认方案。
3. 系统方案和当前默认方案受到删除保护。
4. 新建小说页面可以选择方案，并默认选中默认方案。
5. 新小说获得所选方案的六个模板快照。
6. 修改方案后，已创建小说的模板保持不变。
7. 必要占位符缺失时不能保存模板。
8. 原有小说创作、导出与备份功能继续工作。
9. 全量测试、类型检查、代码规范检查和生产构建通过。

## 测试策略

- 数据库测试：幂等种子、方案唯一名称、默认切换和删除保护；
- 仓库测试：新建、复制、编辑、删除，以及小说快照隔离；
- 规则测试：六步必要占位符校验；
- 输入测试：方案 ID、名称、说明和模板正文校验；
- 页面与构建验证：管理页、新建小说下拉框和原有工作流。
